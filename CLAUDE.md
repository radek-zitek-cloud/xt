# xt team repo

This repository is an xt team's home. Agents here are started by xt, and each gets its identity,
role and the team protocol in its **first prompt**. That first prompt and [protocol.md](protocol.md)
are authoritative for team coordination.

- If you were started by xt: follow your first prompt and protocol.md. When unsure what's going
  on, run `bin/xt brief --as <your name>`.
- If you were *not* started by xt (e.g. a coding agent helping the human with this repo): see
  [README.md](README.md). Don't send team messages or spawn agents unless the human asks you to.
